## TL;DR
- Topic: Improving TCP Bandwidth Claiming
- Method: Testing several methods using basic simulation, discussing drawbacks.
- Project timeline: 1 week
- Results: 
    - Methods exist which permit TCP to retain more bandwidth during traffic or natural drops in network availability.
    - Not all methods are capable of TCP friendliness, causing compatibility issues.
    - These methods may be worth employing, but legacy systems can suffer if too greedy of an approach is taken.
